# Artisan コマンド

## sms:test {#sms-test}

認証情報を確認するために、本物のメッセージを送信します。アプリケーションと同じコードを通って送信されます。

```bash
php artisan sms:test {to} [--provider=] [--message=]
```

| | |
|---|---|
| `to` | 宛先。できれば E.164 形式で：`+15551234567` |
| `--provider` | 使用するプロバイダーキー。デフォルトは `SMS_PROVIDER`。 |
| `--message` | 送信する本文。デフォルトは短いテストメッセージ。 |

```bash
php artisan sms:test +15551234567 --provider=sinch --message="Hello from production"
```

成功するとプロバイダーとメッセージ ID を表示します。失敗するとプロバイダーが返した理由を表示し、0 以外の終了ステータスで終了するので、デプロイスクリプトやヘルスチェックにも使えます。

::: warning 本物のメッセージが送られます
当然、プロバイダーの料金もかかります。自分の番号を使ってください。
:::
