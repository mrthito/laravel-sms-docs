# セキュリティ

<p class="lead">SMS には、ログインコードや注文の詳細、個人の電話番号が載っています。ここでは、それらを守るデフォルトの仕組みと、利用者側で決めるべきいくつかの設定を紹介します。</p>

## パッケージが守ってくれること {#what-the-package-does-for-you}

**認証情報は置いた場所から出ていきません。** API キーやトークンは設定から読み込まれ、そのプロバイダーにだけ送られます。例外メッセージや URL のクエリ文字列に含まれることはなく、OAuth トークンはハッシュ化したキーでキャッシュされるので、キャッシュをダンプしても漏れることはありません。

**プロバイダーのエラーは長さを制限しています。** プロバイダーが拒否の理由を返した場合、デバッグしやすいようにそのメッセージを 200 文字まで残します。生のレスポンス本文を含めることはありません。これらのメッセージは送信失敗時にログに書き出されます。プロバイダーがエラーの中でリクエストの一部をそのまま返してくることもあるので、SMS の失敗ログは機密情報として扱ってください。

**ログの電話番号は伏せ字になります。** パッケージ自身が書き出すログには `***4567` と表示され、番号全体が出ることはありません。

**キューのメッセージは暗号化されます。** キューに入れた SMS ジョブはすべて `APP_KEY` で暗号化されるので、Redis やデータベース、SQS の中でログインコードを読まれることはありません。

**Webhook は安全側に倒して失敗します。** シークレットが設定されていない Webhook エンドポイントは、すべてのリクエストを拒否します。シークレットがある場合、署名は定数時間で比較されます。詳しくは [Webhook](/ja/guide/webhooks) を参照してください。

**入力は送信前にチェックします。** 形式の正しくない番号、空のメッセージ、未知のプロバイダーは、リクエストを送る前にエラーになります。Infobip や Termii のように設定で変更できるプロバイダーのベース URL は、HTTPS でなければなりません。

## 利用者側ですべきこと {#what-s-up-to-you}

- **認証情報は環境変数**かシークレットマネージャーに置き、ソース管理には決して含めないでください。漏れた場合はローテーションしましょう。
- **SMS を送信するエンドポイントにはレート制限をかける。** コードを SMS で送るログインフォームは、「SMS パンピング」詐欺の格好の標的です。攻撃者が高額な番号宛てにメッセージを送らせ、その費用をあなたに負担させる手口です。電話番号ごと、IP アドレスごとに制限をかけてください（下記参照）。
- **Webhook は必要になるまでオフにしておき**、HTTPS で受けるようにしてください。
- **本番環境で `log` ドライバーを使わない。** コードを含むメッセージ本文がそのままログファイルに書き出されます。
- **`APP_KEY` を守る。** キューのメッセージはこのキーで復号されます。ローテーションするときは、すでにキューに入っているジョブも読めるよう、古いキーを `APP_PREVIOUS_KEYS` に記載してください。
- **Laravel とこのパッケージを最新に保つ。** Laravel 11 はすでにセキュリティ修正の提供が終わっています。

## ログインコードのレート制限 {#rate-limiting-login-codes}

Laravel の `RateLimiter` を使えば、電話番号ごとの制限は数行で書けます。

```php
use Illuminate\Support\Facades\RateLimiter;
use MrRijal\LaravelSms\Facades\Sms;

$sent = RateLimiter::attempt(
    key: 'sms-code:'.$request->string('phone'),
    maxAttempts: 3,
    callback: fn () => Sms::to($request->string('phone'))->message("Your code is {$code}")->sendNow(),
    decaySeconds: 600,
);

if (! $sent) {
    return back()->withErrors(['phone' => 'Too many codes requested. Try again in a few minutes.']);
}
```

IP アドレスごとの制限は、ルートに `throttle` ミドルウェアを付けて追加します。たとえば `->middleware('throttle:10,1')` のようにします。
